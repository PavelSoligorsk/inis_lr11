# Комментарии без XSS

Вариант 4. Текст комментария очищается через `sanitize-html` до записи в MongoDB. Helmet ставит заголовки безопасности, CSP разрешает скрипты только с этого же адреса (`script-src 'self'`).

## Запуск

```bash
npm install
npm start
```

Страница комментария: `http://127.0.0.1:4010/`.
